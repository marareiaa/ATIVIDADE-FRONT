# 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte das atividades da disciplina de **Desenvolvimento Front-End**, com o objetivo de aplicar, na prática, os conhecimentos adquiridos em sala de aula sobre construção de páginas web.

Durante o desenvolvimento, foram utilizados conceitos fundamentais de estruturação com HTML, estilização com CSS e interatividade com JavaScript, buscando criar uma interface organizada, funcional e de fácil navegação.

Além do aprendizado técnico, a atividade teve como foco a organização do código, a separação de responsabilidades entre arquivos e a adoção de boas práticas de desenvolvimento.

---

# 🎯 Objetivos

O projeto foi desenvolvido para:

* Aplicar conceitos de HTML5, CSS3 e JavaScript;
* Desenvolver interfaces web funcionais;
* Praticar a organização da estrutura de um projeto Front-End;
* Exercitar a manipulação de elementos da página;
* Compreender a integração entre estrutura, estilo e comportamento;
* Consolidar conhecimentos adquiridos durante a disciplina.

---

# ✨ Funcionalidades

Entre as funcionalidades implementadas no projeto estão:

* Estruturação semântica da página;
* Estilização personalizada utilizando CSS;
* Elementos visuais organizados;
* Interações desenvolvidas com JavaScript;
* Interface intuitiva;
* Navegação simples e objetiva.

# ▶️ Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/marareiaa/ATIVIDADE-FRONT.git
```

2. Acesse a pasta do projeto:

```bash
cd ATIVIDADE-FRONT
```

3. Abra o arquivo `index.html` em qualquer navegador ou utilize a extensão **Live Server** no Visual Studio Code.
